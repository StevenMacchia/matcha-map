# Empty and error states: exact strings

Friendly, short, phone first. Each state is a title, one short line, and one action label. Paste as is. Mascot suggestion in brackets (characters.svg ids).

| State | Title | Line | Action |
|---|---|---|---|
| No pop-ups in view | Nothing here yet | Try zooming out, or add one you know about. | Add your pop-up |
| Nothing today | Nothing today | Mattie found no pop-ups for today. Peek at the weekend. | See this weekend |
| Nothing this weekend | Quiet weekend | No pop-ups lined up for Sat or Sun yet. | See what is coming |
| Location denied | No location, no problem | Type a zip or a city and Mattie will look there. | Enter a zip |
| Zip not found | Hmm, that zip is shy | Check the numbers, or try a city name. | Try again |
| Offline | You are offline | Showing the pop-ups you saw last. Reconnect to see new ones. | Try again |
| Search, no results | Nothing matches that | Try a brand, a city or a drink like hojicha. | Clear search |

Form messages (already in the code): server busy "Mattie is napping. Try again in a little while."; no signal "No connection. Check your signal and try again."; daily limit "That is plenty for today. Come back tomorrow."; stale page "This page has been open a while. Reload it and try again."
