# Ladder

The work on this repo is split into rungs. One worker per rung, run in order. This board is the one place to see who is on what and where it stands. States: pending / running / done / blocked.

Budget for the whole build: under 10% of the weekly usage limit. Spend is noted after each rung as a share of that weekly limit.

| # | Rung | Worker | State | What it does | Spend after |
|---|------|--------|-------|--------------|-------------|
| 1 | Spec and data model | Sonnet subagent | done | Write `SPEC.md`: what the site does, the event schema, the honest rules on Instagram and TikTok. | all-models 10% (no visible change from baseline) |
| 2 | Seed list | Sonnet subagent | done | Research real US matcha pop-up brands and write `data/sources.json`. Only accounts that can be verified. | all-models 10% (unchanged) |
| 3 | Ingestion pipeline | Sonnet subagent | done | `npm run ingest`: pluggable adapters, manual paste intake, geocoding with a cache, `data/events.json`. | all-models 11% |
| 4 | The map | Sonnet subagent | done | MapLibre or Leaflet on OpenStreetMap tiles, clustered pins, date filters, near me, list view, cards. Phone first. | all-models 11% |
| 5 | Review | Sonnet subagent | done | Run ingest end to end, check phone and desktop in the browser, fix what breaks, write `README.md`. | all-models 11%, Fable 3% |
| 6 | Theme | Sonnet subagent | done | Restyle the site as a soft, playful Japanese matcha look: rounded type, cream and matcha palette, cup-shaped pins, mochi clusters. Same words, same layout. | all-models 11%, Fable 3% |
| 7 | Seed list, wave 2 | 4 Sonnet subagents (West, South, Midwest, Northeast) | done | Every major US metro: find many more real pop-up brands, write `data/wave2/<region>.json`, then merge into `data/sources.json`. | all-models 13% |
| 8 | Mascot | Sonnet subagent | done | A round matcha-cup character with a face, used in the header, pins, empty state and About; pastel basemap tint, soft pattern, favicon. Same words, same layout. | all-models 13% |
| 9 | Instagram watch loop | Sonnet subagent | done | A watch list of accounts re-checked on a schedule, the Instagram Graph API adapter made real (captions by username, hashtag discovery), new handles found in captions added as candidates, `npm run watch` and `npm run discover`, setup guide. No scraping behind the login wall. | all-models 13% |
| 10 | Richer cards | Sonnet subagent | done | Each pop-up card gets the post photo, the Instagram or TikTok post link, flavors and menu from the caption, price when stated. Schema, extractor, adapters and card. Starts after rungs 8 and 9. | all-models 14%, Fable 5% |
